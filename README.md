# Employee Attrition Prediction

This project analyzes employee attrition using machine learning to identify key drivers of turnover and support data-driven workforce planning decisions.

## Problem Statement
Employee attrition can be costly and disruptive for organizations. The goal of this project is to predict attrition risk and uncover patterns that help inform retention strategies while balancing business and employee considerations.

## Approach
- Cleaned and prepared an HR dataset with ~1,500 employee records
- Conducted exploratory data analysis to identify attrition trends
- Trained and evaluated multiple classification models:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - XGBoost
- Tuned models using GridSearchCV
- Evaluated performance using accuracy, precision, recall, F1-score, and ROC-AUC

## Key Results
- XGBoost achieved the strongest overall performance
- Model performance improved ~20% over baseline approaches
- Identified key drivers contributing to attrition risk
